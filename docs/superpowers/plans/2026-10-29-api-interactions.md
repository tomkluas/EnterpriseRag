# 全接口交互检查与修复计划

目标：覆盖全部已注册接口的请求契约、认证权限、成功响应和错误路径；修复可复现问题并验证部署入口。沿用现有前端参数契约，不新增功能或修改用户业务数据。

- [x] 管理接口：模型、连接、用户的增查删、默认切换、启停、实际连接测试；内存 SQLite 与外部调用替身测试。
- [x] 知识库接口：创建、上传、文档状态、删除和全库检索；临时文件与隔离数据库，验证归属和失败一致性。
- [x] 前端：核对全部调用者，修复聊天消息、SSE异常与中断恢复、管理操作错误反馈；Node测试与生产构建。
- [x] 数据库连接器：修复实际schema读取与特殊字符；核实数据库检索真实调用链。
- [x] 汇总所有HTTP方法和路径，逐项记录自动测试覆盖；完整后端测试、前端测试、独立评审。
- [x] 复用当前镜像依赖部署，并通过Nginx入口验证只读接口、真实模型和隔离数据增删链路；说明外部服务验证限制。

约束：不删除业务数据、不覆盖现有默认配置；测试数据库隔离，外部服务仅做已授权诊断。权限/缺失ID/重复用户名/上传归属/断流均须有反例。
