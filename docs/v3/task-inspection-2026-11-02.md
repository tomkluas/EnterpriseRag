# 处理任务与分块结果查看

沿用现有任务工作区，列表保留文件、知识库、任务阶段、分块数量及执行次数；详情增加最近一次底座状态和检查时间，并按副本分页预览实际分块正文。未确认的数量显示“待确认”，不计算虚假百分比，不把索引就绪等同于业务已发布。

分块按需通过后端读取，不能让浏览器持服务密钥或直接连接知识平台。两种底座均采用已有只读接口，每页至多 20 块，白名单返回正文、顺序、类型、状态和已有位置，缺页码时不猜测。输出按纯文本展示，不执行分块中的 HTML。预览为只读，不支持编辑或重建索引。

查看任务不等于阅读正文：每次预览都验证租户、任务所有者/系统管理权、任务与副本实际绑定、资料当前阅读权；草稿额外要求资料维护权。资料撤回、角色停用、目标变化、底座未验收时拒绝。外发前和返回正文前复查，避免异步等待期间撤权继续放行。只预览有明确回执、处于就绪状态的副本。

实施与验证顺序：先添加失败测试，覆盖协议分页、归属检查、权限撤销、目标副本错配和只读字段筛选；再接入统一分块结构、两种底座适配、任务查看服务及 HTTP 路由；保存每次状态轮询的可观察结果；最后完成前端预览、错误与翻页交互，并运行相关测试、构建和浏览器检查。

协议依据：[WeKnora 固定版本的分块接口](https://github.com/Tencent/WeKnora/blob/f17ee8a8da901bd658a4cb25f40b5fd41adbfdd7/internal/handler/chunk.go)、[Dify 固定版本的分块接口](https://github.com/langgenius/dify/blob/50abea97062110044f15d0e03ccecadd9ccc87ca/api/controllers/service_api/dataset/segment.py)。本地数量是最近轮询快照，实时预览返回的总数与此快照可能不同，界面分别标明。

验证结果：任务预览 11 项、执行器 6 项、领域 19 项、底座协议 12 项、撤回清理 4 项，共 52 项相关测试通过；前端 3 项测试及生产构建通过。隔离浏览器环境验证了文件与阶段展示、13 块正文的两页读取、HTML 按原文显示、上游故障后清空旧正文及重试、切换任务清空正文、未就绪副本禁止预览、翻页定位到页首，以及 390px 窄屏布局。

本次测试使用临时 SQLite 与模拟 HTTP，未读取实际业务资料，未在真实 WeKnora/Dify 或 PostgreSQL 上联调。正文每页最多 20 块，界面默认每页 10 块；单块超过 20000 字符时明确显示截取提示。预览范围是底座返回的正文分块，不包括图片附件或嵌套子分块。
